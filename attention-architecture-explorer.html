Introduction to Attention Mechanisms

Attention mechanisms revolutionized deep learning by allowing models to focus on relevant parts of the input when producing outputs. Two landmark papers defined this evolution: Bahdanau et al. (2014) introduced attention for neural machine translation, while Vaswani et al. (2017) showed that attention alone was sufficient, eliminating recurrence entirely.

Why Attention Matters: Traditional sequence-to-sequence models compressed entire input sequences into fixed-size vectors, creating an information bottleneck. Attention allows models to "look back" at all input positions, weighted by relevance.

2014: Bahdanau Attention

Paper: "Neural Machine Translation by Jointly Learning to Align and Translate"

First attention mechanism for seq2seq models. Used with RNNs to align source and target sequences dynamically.

2017: Transformer (Vaswani)

Paper: "Attention Is All You Need"

Revolutionary architecture using only attention mechanisms. Introduced multi-head self-attention and positional encodings.

Neural Machine Translation by Jointly Learning to Align and Translate

Key Innovation

Introduced attention as an alignment mechanism between encoder and decoder states in RNN-based seq2seq models.

  • RNN decoder with attention

Vaswani et al. (2017)

Attention Is All You Need

Key Innovation

Showed attention alone is sufficient - no recurrence needed. Introduced self-attention and multi-head attention.

Architecture

  • Stacked encoder-decoder layers
  • Multi-head self-attention
  • Scaled dot-product attention
  • Position-wise feed-forward
  • Positional encodings

Scaled dot-product with query, key, value matrices

What problem does attention solve in seq2seq models?

Attention solves the information bottleneck problem. Traditional seq2seq models compress the entire input into a single fixed-size context vector, losing information for long sequences. Attention allows the decoder to access all encoder states weighted by relevance.

What is the key difference between Bahdanau and Transformer attention?

Bahdanau uses additive attention with RNNs for encoder-decoder alignment. Transformers use scaled dot-product attention with no recurrence, allowing full parallelization and direct connections between all positions.

Why is the attention scaled in Transformers?

Dividing by √dk prevents dot products from growing too large when dimensionality is high. Large values push softmax into regions with tiny gradients, making training difficult. Scaling keeps gradients healthy.

What are Query, Key, and Value in self-attention?

Query (Q): "What am I looking for?"
Key (K): "What do I contain?"
Value (V): "What information do I have?"
Q·K determines attention weights, which are applied to V.

What is multi-head attention and why use it?

Multi-head attention runs multiple attention mechanisms in parallel, each learning different representation subspaces. This allows the model to attend to different aspects simultaneously (e.g., syntax, semantics, position).

Why do Transformers need positional encodings?

Unlike RNNs which process sequentially, self-attention has no notion of order. Positional encodings inject position information using sine/cosine functions, allowing the model to understand token order and distance.

What is the alignment model in Bahdanau attention?

The alignment model learns which source positions are most relevant for predicting each target word. It computes attention scores using a small feedforward network with tanh activation: eij = vT tanh(W1hi + W2sj)

What enables parallel training in Transformers?

Self-attention computes relationships between all positions simultaneously without sequential dependencies. All attention weights can be calculated in parallel using matrix operations, unlike RNNs which must process one timestep at a time.

What is the context vector in Bahdanau attention?

The context vector ci is a weighted sum of encoder hidden states, where weights are attention scores. It provides a dynamic, position-specific summary of the source sequence for each decoder timestep.

Key Formulas Explained

Bahdanau Additive Attention

eij = vT tanh(W1hi + W2sj)
eij: Attention score
hi: Encoder hidden state
sj: Decoder state
W1, W2, v: Learned weights
αij = exp(eij) / Σk exp(eik)

Softmax converts scores to probability distribution

ci = Σj αij hj

Context vector: weighted sum of encoder states

Transformer Scaled Dot-Product Attention

Attention(Q, K, V) = softmax(QKT / √dk) V
Q: Query matrix (what I'm looking for)
K: Key matrix (what I contain)
V: Value matrix (information to retrieve)
dk: Key dimension (scaling factor)
Why Scaling? When dk is large, dot products grow large in magnitude, pushing softmax into regions with extremely small gradients. Dividing by √dk counteracts this effect.
Multi-Head Attention
MultiHead(Q,K,V) = Concat(head1,...,headh)WO

Where each headi = Attention(QWiQ, KWiK, VWiV)

Deep Dive: Technical Details

Understanding Bahdanau Attention Step-by-Step

Step 1: Encoder Processing

A bidirectional RNN processes the source sequence, creating forward and backward hidden states that are concatenated: hj = [h⃗j; h⃖j]

Step 2: Computing Alignment Scores

For each decoder timestep i and encoder position j, compute an alignment score using a small feedforward network:

  • Concatenate or add encoder state hj and previous decoder state si-1
  • Pass through tanh activation with learned parameters
  • Project to scalar score: eij = vT tanh(W1hj + W2si-1)
Step 3: Normalize with Softmax

Convert raw scores to a probability distribution: αij = exp(eij) / Σk=1Tx exp(eik)

Step 4: Compute Context Vector

Weighted sum of encoder states: ci = Σj=1Tx αij hj

Step 5: Generate Output

Concatenate context vector with decoder state and pass through softmax to predict the next token: yi = g(yi-1, si, ci)

Understanding Transformer Attention Step-by-Step

Step 1: Input Embeddings + Positional Encoding

Tokens are embedded and added to positional encodings (sine/cosine functions) to inject position information:

PE(pos,2i) = sin(pos/100002i/d)
PE(pos,2i+1) = cos(pos/100002i/d)
Step 2: Create Q, K, V Matrices

Input is linearly projected into three representations:

  • Query (Q) = XWQ - what each token is looking for
  • Key (K) = XWK - what each token offers for matching
  • Value (V) = XWV - actual information to retrieve
Step 3: Compute Attention Scores

Calculate compatibility between queries and keys using dot product:

  • Score matrix: QKT (each query compared with all keys)
  • Scale by √dk to prevent large values
  • Apply softmax row-wise to get attention weights
Step 4: Apply Attention to Values

Multiply attention weights by value matrix: Output = softmax(QKT/√dk)V

Step 5: Multi-Head Mechanism

Run 8 attention mechanisms in parallel (different WQ, WK, WV for each head), concatenate outputs, and project:

MultiHead = Concat(head1,...,head8)WO
Step 6: Add & Normalize

Residual connection + layer normalization: LayerNorm(x + MultiHead(x))

Step 7: Feed-Forward Network

Position-wise MLP applied to each position: FFN(x) = max(0, xW1 + b1)W2 + b2

Computational Complexity Comparison

Operation Bahdanau (RNN-based) Transformer
Per-Layer Complexity O(n·d²) for RNN + O(n²·d) for attention O(n²·d) for self-attention
Sequential Operations O(n) - must process sequentially O(1) - fully parallel
Maximum Path Length O(n) - through RNN states O(1) - direct connections
Memory Complexity O(n·d) for hidden states O(n²) for attention matrices
Key Insight: Transformers trade memory (O(n²) attention matrices) for speed (parallel computation). For very long sequences (n >> d), the quadratic complexity becomes a bottleneck, leading to variants like Linformer, Performer, and Longformer.

Impact & Legacy

Bahdanau's Influence

  • ✓ Proved attention mechanism's effectiveness
  • ✓ Foundation for all subsequent attention work
  • ✓ Still used in RNN-based architectures
  • ✓ Inspired visual attention in computer vision
  • ✓ Introduced alignment visualization

Transformer Revolution

  • ✓ Enabled modern LLMs (GPT, BERT, T5)
  • ✓ Scaled to billions of parameters
  • ✓ Extended beyond NLP (Vision Transformers)
  • ✓ Spawned efficient variants (Reformer, etc.)
  • ✓ Foundation of ChatGPT, Claude, Gemini
